# MF03 v2.0 - Field Execution, Drone Handover, and Ingestion Specification

## 1. Executive Summary
MF03 (Main Flow 03) establishes the operational field workflow between Mission Scheduling (MF02) and Analysis & Defect Evaluation (MF04). It governs on-site check-in, drone custody handovers, flight telemetry ingestion, field incident reporting, and raw inspection media ingestion with EXIF metadata parsing.

---

## 2. Actors & Permissions
- **Field Inspector (Pilot / Operator):**
  - Performs on-site GPS check-in.
  - Receives pre-flight drone handover and returns custody post-flight.
  - Executes flight and uploads flight telemetry logs.
  - Submits field incident reports.
  - Uploads raw inspection photos/videos.
- **Maintenance / Technical Team:**
  - Performs pre-flight and post-flight physical drone inspections.
  - Signs off on equipment return condition.
- **Flight Operations Manager:**
  - Receives real-time execution lifecycle events (`STARTED`, `COMPLETED`, `CANCELLED`).
  - Receives immediate critical incident notifications.

## 4. Key Business Invariants & Lifecycle Rules
1. **Drone Status Synchronization:**
   - Transitioning mission to `InProgress` synchronously sets `Uav.Status` to `DroneStatus.Flying`.
   - Transitioning mission to `Completed` synchronously resets `Uav.Status` to `DroneStatus.Idle` and marks all active `ResourceBooking` entities as `ResourceBookingStatus.Released`.
2. **Flight Telemetry Constraints:**
   - Mission status must be `InProgress` or `Completed`.
   - Battery remaining percentage must be within `0..100`.
   - Total flight duration must be greater than zero.
   - Max altitude must be non-negative.
   - Telemetry data must be valid JSON format.
3. **Field Incidents:**
   - Minimum description length of 10 characters.
   - Allowed severities: `Low`, `Medium`, `High`, `Critical`.
   - Automatic fallback to mission primary target asset if not explicitly specified.
   - `Critical` severities automatically trigger real-time alert notifications to managers.
4. **Zero-Dependency EXIF Metadata Extraction:**
   - JPEG images are inspected for APP1 EXIF segment headers.
   - GPS Latitude/Longitude and capture timestamp are parsed and used to backfill missing client form-data.
5. **Multi-Assignee Ingestion Access:**
   - Any inspector assigned to the mission with `Accepted` status in `MissionAssignment` is permitted to upload inspection media.
